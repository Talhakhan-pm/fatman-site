# OEM Parts Copy & Realism Guidance

**Target Persona**: Auto Enthusiasts, Professional Mechanics, B2B Shop Buyers.
**Brand Tone**: Technical, Reliable, Precise, Premium (but accessible).

### 1. Title Patterns
*Do not use generic adjectives like "Awesome" or "Super". Stick to functional, spec-heavy naming.*

- **Pattern A (Brand + Spec + Part):** `[Brand/Line] [Key Spec] [Part Name] - [Fitment/Size]`
  *Example: ProSeries 320mm Slotted Carbon-Ceramic Brake Rotor*
- **Pattern B (Application + Part):** `[Vehicle/Engine Type] High-Output [Part Name]`
  *Example: 5.0L V8 High-Output Precision Alternator, 150A*
- **Pattern C (Material + Part + Identifier):** `[Material] [Part Name] kit [Color/Finish] (SKU/Ref)`
  *Example: Forged Aluminum Piston Set - Mirror Finish (Standard Bore)*

### 2. Description Structure
A realistic product description should feel like it was written by an engineer or a very knowledgeable parts catalog editor.

**Format:**
1. **Hook (1 sentence):** The main benefit or direct replacement info.
2. **Core Specs (Bullet points):** Dimensions, materials, tolerances, fitment.
3. **The "Why" (Short paragraph):** Why this part fails less, performs better, or installs easier than standard OEM.

**Example Description (Brake Rotor):**
> Designed for high-thermal capacity applications, these carbon-ceramic rotors offer a 40% reduction in unsprung weight compared to standard cast-iron equivalents.
> 
> * **Diameter:** 320mm
> * **Material:** Aerospace-grade Carbon-Ceramic Matrix
> * **Venting:** Directional curved vanes for maximum heat dissipation
> * **Fitment:** Direct bolt-on replacement for factory 6-piston caliper setups.
> 
> Ideal for both aggressive street driving and track-day use, delivering fade-free performance under extreme loads.

### 3. Words to Avoid / Words to Use
**Avoid:**
- "Amazing", "Best", "Incredible", "Ultimate"
- Fluffy marketing jargon ("Experience the thrill of braking")
- Overly emotional appeals

**Use:**
- "Precision-machined", "OEM-equivalent", "Direct fit", "Tolerance", "Forged", "Billet", "Anodized"
- Objective metrics (e.g., "Rated for up to 800 HP", "Reduces operating temp by 15°C")
