# Engines Product-Card Copy Guidance — Round 2

## Goal
Make these listings read like believable U.S. engine inventory. Keep the copy specific to the visible engine style, avoid ad-speak, and use the image only as visual support unless real catalog specs confirm exact displacement, fitment, or output.

## Best Use by Asset

### `engine-ecoboost-v6-twin-turbo.png`
Use for:
- modern turbo V6 replacement engines
- late-model truck/SUV performance or replacement listings
- direct-injection / twin-turbo style assemblies

Suggested title patterns:
- Twin-Turbo V6 Engine – Complete Assembly
- Modern Turbo V6 – Accessory-Ready Engine Package
- Replacement V6 Engine – Twin-Turbo Configuration

Suggested description style:
- Complete modern V6 engine assembly with twin-turbo hardware, composite intake components, and factory-style accessory packaging. Best used for premium replacement or late-model performance-oriented listings.

### `engine-long-block-v6-fwd.png`
Use for:
- front-wheel-drive / transverse V6 listings

- Cast Aluminum V6 Engine – Long Block Assembly

Suggested description style:
- Clean V6 long block assembly with compact front dress, cast aluminum surfaces, and replacement-engine catalog framing. Good fit for mainstream passenger-car and crossover inventory where a neutral, realistic image is needed.

## Tone Rules
- Sound parts-counter smart, not salesy.
- Avoid: beast, monster, insane, ultimate, race-proven, dyno-tested.
- Prefer: complete assembly, long block, accessory-ready, supercharged, twin-turbo, compact, cast aluminum, composite intake, factory-style layout, replacement engine.
- Do not invent OEM names, horsepower, tested status, mileage, emissions status, or exact fitment.

## Anti-Repetition Detail Bank
Rotate these details instead of repeating the same copy:
- composite intake manifold
- twin-turbo hardware
- compact front dress
- transverse-ready layout
- roots-style blower case
- cast aluminum long block
- polished classic top-end hardware
- modern direct-injection style packaging
- industrial-duty accessory layout
- compact turbo plumbing

## Practical Integration Advice
- Match copy to what is visibly shown in the asset.
- For grid cards, keep titles neutral and concise.
- For PDPs, add application detail only if it exists in the real product data.
- Use the more distinctive images (`supercharged`, `flatplane`, `big-block`) selectively so the catalog does not feel repetitive or over-stylized.
