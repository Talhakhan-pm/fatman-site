# Engines Product-Card Copy Guidance

## Goal
Make engine listings feel like believable catalog inventory, not ad copy. Keep titles specific, restrained, and parts-led. Descriptions should sound like a knowledgeable parts seller describing configuration and fitment context without overclaiming.

## Title Pattern Options
Use 1 pattern per listing to avoid repetition.

1. **[Engine family/type] [configuration] – [key visual/config detail]**
   - Crate V8 Engine – Black Valve Cover Performance Setup
   - Inline-6 Turbo Engine – Polished Charge Pipe Assembly
   - Heavy-Duty Diesel Engine – Complete Long Block Assembly

2. **[Displacement/class if known] [engine type] – [assembly state]**
   - 6.7L Diesel Engine – Complete Running Assembly
   - Small Block V8 – Long Block Engine Package
   - Turbo Inline-6 – Accessory-Ready Engine Assembly

3. **[Use case] [engine type] – [finish/style cue]**
   - Performance Crate Engine – Matte Black Accessory Drive
   - Restoration V8 Engine – Polished Carbureted Setup
   - Street/Strip V8 – Aluminum Front Drive Assembly

## Description Pattern
Keep to 1-2 sentences.

**Formula:**
- Sentence 1: State assembly type + standout visible components.
- Sentence 2: Add fitment/swap/use-case flavor or condition/setup note.

**Examples:**
- Complete crate-style V8 assembly with black valve covers, serpentine front drive, and machined accessory hardware. Built for performance-oriented listings where buyers expect a clean turnkey engine presentation.
- Turbocharged inline-6 engine setup with visible charge piping, complete accessory mounting, and detailed hose/clamp finishing. Best suited for premium performance or swap-package style inventory cards.
- Heavy-duty diesel engine assembly with cast block construction, fuel system hardware, and full front accessory layout. Good fit for commercial, replacement, or work-truck category listings.

## Tone Rules
- Sound informed, not hyped.
- Avoid words like: revolutionary, beast, insane, ultimate, monster.
- Prefer: complete assembly, long block, crate-style, accessory-ready, polished, cast, machined, turbocharged, carbureted.
- Do not claim tested/running/mileage unless known from actual listing data.
- Do not invent OEM brand names, trim names, or certifications.

## Non-Repetitive Detail Bank
Rotate these so listings do not all read the same:
- black valve covers
- machined front accessories
- polished intake hardware
- cast block finish
- complete long block layout
- accessory-ready front drive
- visible turbo hardware
- carbureted top-end setup
- commercial diesel configuration
- restoration-style assembly

## Safe Description Length
- Title: 5-10 words ideal
- Description: 18-35 words ideal

## Practical Ecommerce Notes
- Product-card copy should match what is visible in the image.
- Use cleaner, more neutral titles for grid cards.
- Save more specific configuration notes for detail pages when real specs exist.
