# Fatman Parts Social Content System

Status: working draft
Purpose: define the social-media automation segment separately from the catalog/storefront automation segment.

## Key framing

Fatman now has two separate automation segments:

1. Catalog/storefront automation
   - Parse/source parts data.
   - Improve image coverage.
   - Push safe live catalog slices.
   - Keep fitment/product quality high.

2. Social/content automation
   - Turn catalog progress, product categories, trust signals, customer education, and drops into branded posts.
   - Generate visual systems, captions, variants, and schedules.
   - Publish through OmniSocials to connected Fatman channels.

These can feed each other, but they are not one loop. Catalog automation creates raw material. Social automation packages it into customer-facing attention.

## Brand direction

Use the current Fatman visual language:

- Deep navy / charcoal: `#0b1220`, `#111318`, `#1e293b`
- Bright orange action accent: `#ea580c`
- Darker orange hover/accent: `#c2410c`
- Success green for fit/trust: `#16a34a`
- Light background: `#f8fafc`, `#f7f8fa`
- Text dark: `#0f172a`, `#1e293b`, `#334155`

General feel:

- Mechanic/shop credible, not cute.
- Clean ecommerce trust, not meme spam.
- Bold hooks, short readable claims.
- Real benefit first, part visual second.
- Avoid fake OEM logos, automaker logos, burned-in text on AI part images, or claims we cannot operationally back.

## Visual system candidates

### 1. Dark premium card

Best for Facebook/Instagram feed posts.

Layout:

- Dark navy gradient background.
- Big hook at top-left.
- Product/category image on white card or cutout panel.
- Orange CTA pill.
- Small trust strip along bottom.

Example hook:

`STOP GUESSING FITMENT`

Trust strip examples:

- `OEM-style parts`
- `Vehicle fitment checks`
- `Fast U.S. shipping`
- `VIN help available`

### 2. White ecommerce card

Best for clean product/category posts.

Layout:

- White or light-gray background.
- Studio product/category image centered.
- Fatman orange border or corner tag.
- 2-3 benefit bullets.
- Site URL small at bottom.

Good for catalog drops and product category highlights.

### 3. Mechanic problem/solution post

Best for education and engagement.

Layout:

- Left: problem statement.
- Right: part/category visual.
- Bottom: solution CTA.

Example:

`Truck running hot? Don’t guess parts blindly.`
`Search cooling parts by vehicle and verify fit before you buy.`

### 4. Fitment confidence post

Best for differentiating Fatman from generic marketplaces.

Layout:

- Green check badge.
- Vehicle selector/search UI screenshot or stylized UI panel.
- Short claim: `Check fit before checkout.`

Avoid saying guaranteed fit unless the operational policy supports it for that exact item/order path.

### 5. Catalog drop post

Best when a new year/make/category batch goes live.

Layout:

- Big batch headline.
- Category tiles, not one isolated AI part.
- CTA to search the live site.

Example:

`New Ford OEM catalog batch added`
`Electrical, drivetrain, steering, HVAC and more.`

Only use when live catalog actually has the batch published.

## Post pillars

### A. Trust / positioning

Goal: explain why Fatman is safer than guessing on eBay/random listings.

Post ideas:

1. `Stop guessing if the part fits.`
2. `OEM-style parts with fitment checks before checkout.`
3. `Search by vehicle, part name, or part number.`
4. `Built for drivers, mechanics, and shops that need the right part.`
5. `Need help? Send VIN/details before ordering.`

### B. Product/category spotlight

Goal: promote shoppable categories without relying on a single generic AI part image.

Structure:

- Hook tied to symptom/use case.
- Category/product family.
- Fitment/value claim.
- CTA.

Examples:

- Cooling: overheating, radiator, fan clutch, hoses.
- Electrical: relays, switches, wiper motors, modules.
- Drivetrain: transmission parts, shafts, clutch components.
- Steering/suspension: stabilizer links, pitman arms, power steering parts.
- HVAC: heater cores, controls, blower parts.

### C. Problem education

Goal: give useful mechanic/customer guidance.

Post examples:

1. `Before replacing a part, match year/make/model/engine.`
2. `Why OEM part numbers matter.`
3. `Used OEM vs aftermarket: when each makes sense.`
4. `Fitment notes can change between trims.`
5. `A photo alone does not prove fitment.`

### D. Inventory/catalog progress

Goal: show momentum without exposing internal staging/import terms.

Customer-safe language:

- `New parts added.`
- `More Ford categories are now searchable.`
- `Fresh catalog update live.`
- `More fitment-backed listings are coming online.`

Avoid internal terms:

- `CHARM`
- `staging`
- `import batch`
- `checkpoint`
- `parser`
- `AI representative image`

### E. Offer / CTA posts

Goal: get clicks and messages.

Examples:

1. `Need the right part? Search Fatman Parts first.`
2. `Not sure it fits? Ask before you order.`
3. `Search by vehicle or part number.`
4. `Fast U.S. shipping on available parts.`
5. `Built to help you buy the right part the first time.`

### F. Behind-the-scenes, but customer-safe

Goal: make the brand feel alive without revealing messy internal ops.

Examples:

- `We’re cleaning up old-school parts data so customers can search smarter.`
- `Every week we’re adding more searchable categories.`
- `The mission: fewer wrong parts, faster repairs.`

## AI/MCP generation workflow

Desired pipeline:

1. Select post pillar and product/category theme.
2. Pull real catalog/category context from Fatman data/site.
3. Generate 3 caption options.
4. Generate 2-4 visual directions in the approved brand system.
5. QA visuals:
   - no fake logos
   - no automaker logos
   - no burned-in unreadable text
   - no numbers/labels on product images unless intentional UI overlay
   - readable at mobile feed size
   - customer-safe claims
6. Pick one final image.
7. Publish/schedule through OmniSocials.
8. Record post ID, channels, status, and live URLs.

Possible MCP/tool needs:

- Image generation/editing server for branded post artwork.
- Browser/design automation for HTML/SVG/social-card generation.
- Fatman catalog query tool or script to source real categories/products.
- OmniSocials MCP for publishing/scheduling.
- Optional analytics MCP/API later for feedback loop.
